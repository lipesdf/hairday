# HairDay

O **HairDay** é uma aplicação web de **agendamento para barbearias**, desenvolvida durante um projeto da **Rocketseat**.

A aplicação permite visualizar os horários disponíveis e realizar agendamentos de forma simples e organizada, facilitando o gerenciamento dos atendimentos.

## Sobre o projeto

O objetivo do HairDay é oferecer uma solução prática para o controle de agendamentos de um cabeleireiro.

O projeto foi desenvolvido com foco em **JavaScript**, utilizando manipulação do DOM, consumo de dados e integração com um servidor local para simular uma API.

## Funcionalidades

* 📅 Visualização dos horários disponíveis
* ✂️ Agendamento de clientes
* 🕐 Organização dos horários por período
* ➕ Criação de novos agendamentos
* 🗑️ Remoção de agendamentos
* 💾 Persistência dos dados através de servidor JSON
* 📱 Interface simples e responsiva

## Tecnologias utilizadas

* **HTML5** — estrutura da aplicação
* **CSS3** — estilização e responsividade
* **JavaScript** — lógica e interatividade
* **Webdriver** — automação/testes da aplicação
* **ServeJSON** — criação de um servidor local para armazenamento e gerenciamento dos dados

## ▶️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/lipesdf/hairday.git
```

### 2. Acesse a pasta

```bash
cd hairday
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o servidor JSON

```bash
npm run server
```

### 5. Execute a aplicação

Em outro terminal, execute o projeto utilizando o comando configurado no `package.json` ou abra a aplicação através do seu servidor de desenvolvimento.
